ネトロシェーダー / HSP3.7 HGIMG4

起動
  main.hsp をHSP3.7エディタで開いてF5で実行。
  resフォルダをmain.hspと同じ場所に置いてください。
  Spaceで背景OFF→マス目→一枚絵→OFF、Eで発光・残像ON/OFF、Escで終了。
  960x540のウィンドウ全体へ適用します（排他的フルスクリーンではありません）。

調整（main.hsp冒頭）
  mint_gain   : 水緑色の発光倍率
  orange_gain : オレンジの発光倍率
  spread_gain : 周囲1ドットの膨張強度
  halo_gain   : 周囲2ドットまでの柔らかい発光強度
  sw / sh     : ゲーム内部解像度

組み込み
  gsel 1 / redraw 0 ～ redraw 1 のサンプル描画をゲーム描画に置換。
  バッファID 1・2・3・4・5を使用（5は背景画像）。既存ゲームと衝突する場合は変更してください。
  バッファ1をコピーするとシェーダーが適用されます。
  バッファ2に処理済み結果を保存し、最終拡大は通常コピーです。
  HUDを光らせたくない場合は、最後のgzoom後、redraw 1の前に描画。
  実行ファイル配布時は独自シェーダー3ファイルとres/cyberpunk_city.pngも同梱してください。

仕組み
  水緑色 #40FFC0 とオレンジ #FF8028 の近似色を抽出します。
  色相に近い正規化RGB距離を使い、暗色・無彩色を除外します。
  3x3最大値で膨張し、5x5重み付き平均で外周をにじませます。
  最終色 = 元画像 + 膨張成分 + にじみ成分（上限1.0）。
  白飛びする場合はgainを下げてください。
  全画面26テクスチャ参照/画素。320x180で約150万参照/フレーム。
  描画バッファは初期化時のみ確保。CPUのピクセル読み出しはありません。
  低解像度で合成してから拡大するため、発光にもドット感が残ります。
  RGB色判定なので、同じ色の背景やUIも発光します。

文字コード
  main.hsp / README.txt : Shift-JIS (Windows CP932)、BOMなし
  .vert / .frag : ASCII（Shift-JIS互換）

赤・緑の残像（テールランプ風）
  赤と緑の移動ランプをサンプルに追加。
  trail_half_ms : 減衰の半減時間（初期値180ms）。長くするなら300程度。
  trail_gain    : 残像の加算強度（初期値0.70）
  red_gain / green_gain : 赤／緑の蓄積強度
  2枚の履歴バッファを交互に更新し、実際に通過した位置に残像を残します。
  時間基準の指数減衰に、微光が永久に残らないための減算を併用。
  静止しているランプの履歴は加算で飽和します。
  Eで効果OFFにすると履歴を消去し、再ON時の古い残像を防ぎます。
  赤／緑の成分優勢度で判定し、水緑色・オレンジ・白を対象から除外。
  同じ赤・緑の背景やUIも対象。カメラ移動も画面座標で尾を引きます。
  初期化時・シーン切替時はバッファ3・4を黒でクリアしてください。
  太い尾にするには元のランプを数ドット幅で描画してください。
  更新後もHSPコンパイルのみ確認。GPUの実描画・性能は未確認です。
背景切替
  Spaceで OFF（黒）→マス目→一枚絵→OFF の順に循環します。
  初期状態はOFF。Eキーの発光・残像切替とは独立しています。
  切替時に残像履歴を消去します。ランプと色見本は全モードで表示。
  一枚絵はres/cyberpunk_city.png（内蔵画像生成ツールで生成）。
  夜の高架道路とネオン都市を描いたサイバーパンク風背景です。
  起動時に一度だけ読み込み、320x180に縮小して描画します。
  背景のネオンにも色選択グロー／残像処理が適用されます。
  生成プロンプトはres/background_prompt.txtに記録しています。
