ネトロシェーダー / HSP3.7 + HGIMG4

概要
  水緑色・オレンジの選択的な膨張と加算発光、赤・緑の残像、
  発光強度の明滅を実装した2Dサンプルです。
  内部320x180で処理し、960x540へ拡大表示します。
  「全画面」はウィンドウ内の画面全体への効果を意味します。

起動と操作
  HSP3.7を導入し、main.hspをHSPエディタで開いてF5で実行します。
  resフォルダはmain.hspと同じ場所に置いてください。
  Space : 背景 OFF（黒）→マス目→一枚絵→OFF
  E     : 発光・残像のON/OFF
  P     : 水緑色・オレンジの明滅ON/OFF
  Esc   : 終了
  初期状態は効果ON、背景OFF、明滅OFF。長押しで連続切替しません。
  背景・効果を切り替えると、古い残像履歴を消去します。
  Eで効果OFF中は明滅も停止し、Pの設定と位相は保持します。

設定（main.hsp冒頭）
  view_width / view_height : 表示サイズ（960 / 540）
  sw / sh                 : 内部解像度（320 / 180）
  mint_gain / orange_gain : 基準の発光倍率（各0.85）
  spread_gain             : 周囲1ドットの膨張強度（0.28）
  halo_gain               : 周囲2ドットまでのにじみ強度（0.75）
  trail_half_ms           : 残像の半減時間（180ms）
  trail_gain              : 残像の合成強度（0.70、0～1を推奨）
  red_gain / green_gain   : 赤／緑の蓄積強度（0.90 / 0.80）
  pulse_period_ms         : 明滅周期（2400ms）
  pulse_min / pulse_max   : 基準発光に対する倍率範囲（0.15～1.35）
  時間設定は正の値、強度は非負の値を使ってください。
  内部解像度を変更する場合、サンプルの物体座標も調整してください。

処理と組み込み
  メインループは次のサブルーチンを順に呼びます。
  read_input      : キー入力とモード切替
  update_effects  : 経過時間・明滅・発光パラメーター更新
  draw_scene      : 背景とサンプル物体の描画
  update_trails   : 前フレームの減衰と赤・緑の蓄積（効果OFF時は省略）
  compose_effects : グロー適用と残像の加算
  present_frame   : 処理結果の拡大表示
  clear_trails    : 履歴消去（初期化・切替で共用）

  自分のゲームに組み込む場合は、draw_sceneのredraw 0～1の間を
  ゲーム画面の描画に置き換えます。初期化と描画順序を維持してください。
  シーン切替時はgosub *clear_trailsを呼びます。
  光らせないHUDはpresent_frameのgzoom後、redraw 1の前に描画します。

  使用バッファ:
    0 : 表示画面
    1 : 元画像（コピー時にグロー／赤緑抽出シェーダーを適用）
    2 : 合成済み画像
    3 / 4 : 交互に読み書きする残像履歴
    5 : 背景画像（起動時に一度だけ読み込み）
  既存ゲームとIDが衝突する場合は、関連箇所をまとめて変更してください。

効果の仕様
  水緑色 #40FFC0・オレンジ #FF8028 の近似色を正規化RGBで選択し、
  3x3最大値で膨張、5x5重み付き平均でにじませて元画像へ加算します。
  グロー処理は26テクスチャ参照/画素。残像と表示の参照は別途発生します。
  明滅は実時間の正弦波で、2色を1/4周期ずらします。
  OFFに戻すと基準強度に復帰します。元画像の色は変更しません。

  残像は赤／緑の成分優勢度で抽出し、実時間の指数減衰と微量の減算で
  消去します。半減時間は指数成分の設定で、実際は減算分も減衰します。
  元の水緑色・オレンジ・白は残像の対象外です。
  静止した対象色は蓄積して飽和します。白飛びする場合は強度を下げます。
  背景やUIの対象色も発光・残像の対象です。カメラ移動も尾を引きます。
  残像は画面座標に残ります。太い尾は元のランプを数ドット幅で描画します。
  描画バッファは起動時のみ確保し、CPUでのピクセル読み出しは行いません。

ファイルと配布
  main.hsp                     : サンプル本体（Shift-JIS / CP932、BOMなし）
  res/shaders/neoretro.vert     : 共通頂点シェーダー
  res/shaders/neoretro.frag     : グロー・赤緑抽出
  res/shaders/trail_decay.frag  : 残像減衰
  res/cyberpunk_city.png        : AI生成のサイバーパンク背景
  res/background_prompt.txt    : 背景の生成プロンプト
  LICENSE_NOTES.txt             : 出典・利用許諾の整理
  THIRD_PARTY_NOTICES.txt       : HGIMG4・ANGLEの通知文
  シェーダーはASCII、本文書とライセンス文書はCP932です。
  実行ファイルを配布する場合は、res以下の必要な画像・シェーダーと
  必要な著作権・ライセンス通知を同梱してください。
  独自部分のオープンソースライセンスは未指定です。
  コンパイル生成物は.gitignoreで除外しています。
